# Speedometer App Installation (APK)

Download and install the APK directly on your Android phone:

### Download Options

1. **[Speedometer-arm64.apk (17.8 MB)](./Speedometer-arm64.apk?raw=true)** *(Recommended)*
   - Optimized for all modern 64-bit Android smartphones (Samsung Galaxy A-series/S-series, Google Pixel, OnePlus, Xiaomi, Oppo, Vivo, Motorola, etc.).
   - Smaller file size, faster download, and best battery/rendering performance.

2. **[Speedometer-universal.apk (48.3 MB)](./Speedometer-universal.apk?raw=true)**
   - Universal package containing binaries for all chip architectures (ARMv7, ARM64, x86_64).
   - Guaranteed to install on any Android phone running Android 7.0 (API 24) or newer.

---

### How to Install on Your Phone

1. Open this GitHub repository on your phone browser (Chrome/Samsung Internet).
2. Tap on **`Speedometer-arm64.apk`**, then tap **"Download raw file"** (or **Download**).
3. Once downloaded, open the notification or tap the downloaded `.apk` file.
4. If prompted with *"For your security, your phone is not allowed to install unknown apps from this source"*:
   - Tap **Settings** in the popup.
   - Toggle **"Allow from this source"** to ON.
5. Tap **Install**, then tap **Open**.
6. When prompted, grant **Location Permission** ("While using the app" / "Precise location") so the speedometer can measure your real-time GPS velocity.
